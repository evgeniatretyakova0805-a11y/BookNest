# BookNest

BookNest — учебный проект сайта библиотеки.

## Страницы сайта

- `index.html` — каталог книг с поиском и фильтрами.
- `book.html` — карточка книги «Маленький принц» с описанием и отзывами.
- `loan.html` — форма оформления выдачи книги.

## Использованные технологии

- HTML5
- Семантическая разметка
- Встроенная проверка форм
- Lighthouse для проверки доступности

## Результаты проверки

Все три HTML-файла проверены с помощью W3C Validator без ошибок. Каждая страница получила 96 баллов из 100 по категории Accessibility в Lighthouse.
